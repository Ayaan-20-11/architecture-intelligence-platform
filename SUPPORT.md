# Support

## Asking a question

Use [GitHub Discussions](../../discussions) for questions, ideas, show-and-tell, and adapter
proposals — this is the right place for "how do I..." and "would you accept..." conversations that
aren't yet a concrete bug or feature request.

## Reporting a bug

Open a [bug report issue](../../issues/new/choose) using the "Bug report" template. Include the
version/commit, what you expected, what happened, and reproduction steps.

**Do not report security vulnerabilities as public issues** — see [`SECURITY.md`](SECURITY.md).

## Requesting a feature

Open a [feature request issue](../../issues/new/choose) using the "Feature request" template, or
start a Discussion first if it's still an open-ended idea.

## Documentation

Start with [`README.md`](README.md) for a project overview and Quick Start, then
[`docs/`](docs/) for the full reference (architecture, canonical model, graph/evidence model,
ingestion, analyses, OpenTelemetry, security model, adapter development). See
[`docs/development.md`](docs/development.md) for running the project locally.
