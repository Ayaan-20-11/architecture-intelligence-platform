# PoC Specification

The original Architecture Intelligence Platform PoC specification is
`Architecture_Intelligence_Platform_PoC_Specification_Python.pdf`, at the repository root. It's the
source-of-truth design document the very first implementation iterations (0-9, see
`IMPLEMENTATION_PLAN.md`) were built against: the Canonical Model, the OpenAPI/AsyncAPI/manifest
adapters, the Neo4j graph model, the five deterministic analyses (A1-A5), and the read-only LLM
query subsystem. Everything documented under `docs/` today builds on top of what that PoC
established; this file is kept as a pointer to it, not a duplicate, since it predates every
markdown-based specification in this directory and exists only as a PDF.
