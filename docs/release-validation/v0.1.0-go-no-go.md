## Known, disclosed limitations (not blockers)

Per `ROADMAP.md`, these are pre-1.0 by design and are documented as such, not hidden:

- Canonical Model, REST API surface, Graph Schema, Adapter SPI, and configuration format are not
  yet guaranteed stable — expect breaking changes on a minor bump.
- No Kubernetes/cloud discovery yet (`v0.2` candidate).
- The natural-language query layer requires an LLM provider API key; everything else works without
  one.

## Recommendation

Every piece of evidence gathered this session — across two alpha releases, an external review, an
independent smoke test, and repeated fresh-environment verification rather than assumption — supports
a **GO**. Both gaps surfaced by `v0.1.0-alpha.1`'s own testing (the release-pipeline race, and the
non-root fix never having been checked against a real pulled artifact) are now closed and
independently re-verified under `v0.1.0-alpha.2`. No open defect, security finding, or unresolved
review comment remains.
